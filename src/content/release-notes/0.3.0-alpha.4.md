# NSM Flow 0.3.0-alpha.4

## Public source and downloads

NSM Flow is now a public MIT-licensed repository with installation instructions,
privacy and model-license guides, and a cross-platform test matrix. Product and
download links inside the app open the public GitHub pages.

## NSM Flow identity

The coloured tray icon now uses NSM Flow's waveform mark. The original Handy
application foundation remains credited; its hand logo is no longer displayed.

## Linux alpha

Linux x64 DEB, RPM and AppImage packaging includes speech runtime libraries and
third-party license texts. The initial build target is Ubuntu 22.04/glibc; X11
is recommended. The X11/KDE window backend avoids a GPL-only Hyprland dependency.
Wayland, other distributions and physical microphone/paste behavior need device
testing. Linux updates are manual in this alpha.

Mac installers remain Developer ID signed and Apple notarized. Windows x64
installers remain unsigned and may show SmartScreen warnings. Downloaded speech
models and optional AI providers retain their own licenses and terms. Indian
vocabulary support is included; universal accent accuracy is not claimed.
