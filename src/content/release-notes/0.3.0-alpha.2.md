# NSM Flow 0.3.0-alpha.2

## Reliable updates

Mac update bundles now install correctly and retain Apple's notarization ticket.
Downloads use fixed versioned URLs, with checksums and source provenance for each platform.

## Your text, your choice

History now has separate transcript retention and a confirmed **Delete all history** action.
Existing transcripts stay intact during upgrade. Automatic transcript expiry preserves saved entries.
Local recordings are still deleted after transcription by default.

## Secure optional cloud credentials

Provider API keys move to the operating system's credential store. Settings show whether a key is saved without reading it back into the interface.
If the vault is locked, existing keys are preserved and NSM Flow explains how to finish migration.
Local dictation continues to work without an API key or cloud sign-in.

## Faster recovery

Cancel responds even when a model download stalls. Partial downloads remain available to resume.
Failed settings saves revert and show an error. Dependencies and acceptance checks have been refreshed.
