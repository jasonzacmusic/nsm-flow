# NSM Flow 0.3.0-alpha.3

## Review before updating

Available updates show their version and full release notes before you choose **Update and restart**. Cancel keeps your current app running. Background discovery never installs an update.

## Protect live dictation

An update can start only after recording and transcription finish. Dictation stays paused while an approved installation runs. If a download fails, you can continue dictating and retry the update.

This release retains the classroom notation fixes, secure optional API-key storage, transcript retention controls and resumable model downloads introduced in 0.3.0-alpha.2. Mac packages are signed and notarized; Windows installers remain an unsigned alpha.
