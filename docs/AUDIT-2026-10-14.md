# NSM Flow public-release audit — 14 October 2026

## Verdict

NSM Flow has a working local desktop dictation foundation and distributable
Mac/Windows alphas. It was **not already a complete public cross-platform
release**: the source repository was private, download links were broken,
Windows was unsigned, and Linux release packaging had not run. This audit prepares
public testing with explicit platform limits; it does not certify stable quality,
every OS version, every Indian accent, or every optional model/provider.

Brand: **NSM Flow — free, open-source voice dictation with local speech recognition
and Indian vocabulary support.** Nathaniel School of Music is the maintainer;
Handy remains credited as the foundation. The source is MIT licensed, including
NSM additions. Model weights and dependencies retain their individual licenses.

## Improvements delivered by this audit

- Replace obsolete alpha.1 documentation and shared `/releases/latest` links
  with version-specific alpha.4 downloads. The shared Labs repository's newest release
  belonged to another product, so old links returned 404.
- Add a public installation guide for ordinary users, a source build guide,
  privacy/network explanation, model-license inventory and physical test matrix.
- Replace Handy clone URLs, contributor support addresses and feature-freeze
  instructions with this independent fork's workflow. Preserve upstream credit.
- Add NSM's copyright to the MIT license and document the separate model terms.
- Add Linux to `all-platforms` and a `linux-only` scope. Remove unavailable hard
  pins in the unused Ubuntu 24.04 path, package official ONNX Runtime in both DEB
  and RPM, fix Linux checks that still searched for the `handy` executable, and
  run package smoke checks without inherited build-library paths.
- Avoid linking GPL-only Hyprland helpers on Linux: use a target-only vendored
  `active-win-pos-rs` 0.10.0 X11/KDE backend with a compatible kdotool constraint.
  Both upstream licenses and the exact modification are retained. Mac/Windows
  keep the accepted registry 0.11.0 dependency. Hyprland-specific detection is
  outside this release's claims.
- Collect resolved target/frontend license texts into resources on every build target;
  reject the known GPL-only dependency in that target's reachable graph.
- Add security-reporting instructions and ignore common local secret/signing
  files. Make the source public, enable GitHub secret scanning/push protection and private
  vulnerability reporting, and verify unauthenticated downloads during publication.

## Indian recognition and AI claims

The India lexicon, gated spelling aliases and music rules exist in source and
have regression tests. A prior report contains a short 20.58-second Indian-English
fixture; this is useful anecdotal evidence, not a representative accent benchmark.
The supplied vocabulary can improve proper nouns and music spelling, but there
is no evidence of a newly trained NSM acoustic model.

Multilingual Whisper supports a variety of Indian languages, while English-only
Parakeet models do not support general Indian-language transcription. Language
lists and speed/accuracy scores are upstream catalog metadata. Mixed languages,
regional accents, noise, microphones and device speed need measured testing.
The recommended public wording describes vocabulary support and avoids a claim
of superior or universal Indian-accent accuracy.

Recognition is local after the model download. Default formatting selects a
local custom server and falls back to local rules without a configured LLM
model. Optional cloud or remote-custom formatting sends transcript/prompt text
there and may cost money. “Free” describes the app and local workflow, not all
providers. Google profile sign-in is optional and is not an entitlement portal.

## Privacy and security review

Reviewed recording/history retention, settings, model download cancellation,
credential vault migration, OAuth PKCE/state, paste coordination, updater trust,
Tauri capabilities and release verification tools. Source recordings default to
immediate deletion after processing; text history persists until configured
otherwise. Local database, clipboard, debug logs and backups are not encrypted
or globally erased by history deletion.

Gitleaks 8.30.1 scanned all reachable local refs: **722 commits, 4.89 MB of changed
content, zero detected leaks** at baseline. This is scanner evidence, not a proof
that no sensitive material can exist. The final all-ref rescan covered **734 commits, 5.05 MB, zero detected leaks**.
Signing secrets are referenced through
environment/Keychain mechanisms, not committed literal keys. The existing public
updater key is intentionally public.

`bun audit` reported **no JavaScript advisories** on this date. RustSec identified
three lockfile vulnerability findings plus maintenance/unsoundness warnings:

## Linux RPM packaging repair

The Tauri/rpm 0.16-generated RPM omitted the legacy uncompressed archive-length
field required by Ubuntu 22.04's `rpm2cpio` and contained a wrong uncompressed
payload digest. The upstream `Sha256Writer` hashes full input buffers before the
compressor reports how many bytes were written; a partial write can duplicate
hashed data. The initial package failed the audit and was never publicly released.

The final implementation uses the distribution's `rpmbuild` to package the
already-built DEB payload with stripping disabled. It verifies RPM header/payload
digests, extraction, equality of every application file/permission/symlink with
the DEB, and isolated CPU launch. Application files and models are not modified.
The RPM metadata uses `0.3.0~alpha.4`, the RPM prerelease spelling; the executable
reports `0.3.0-alpha.4`. Other distributions still need installation acceptance.

Fix and verify these in the next native release; successful locale-file coverage
does not establish that every runtime lookup exists.

do not promote the separate authenticated Nathaniel Labs catalogue into the
public storefront. The shared `/products/nsm-flow` page still requires Labs
Platform attention; GitHub is the verified public entry point.
